# YATRI GO visual refresh

## Goal
Make the existing interface more attractive and engaging while preserving its working travel-planning, marketplace, map, booking, and dashboard flows.

## Design direction
- Apply the selected Modern Transit Hero composition to YATRI GO’s actual AI budget-planning experience.
- Use the selected Modern Railway palette: charcoal, signal red, steel blue, and ticket-stock cream.
- Use Outfit for headings and Figtree for body copy.
- Keep the interface simple and credible, with crisp edges, restrained shadows, strong travel photography, and editorial rhythm.
- Avoid gradients, glass effects, decorative blobs, oversized pills, and generic AI/SaaS styling.

## Implementation
- Recompose the homepage opening around a centered, image-backed brand statement and a prominent functional trip-planning panel.
- Preserve all existing planner fields and navigation behavior while improving hierarchy, grouping, and interaction feedback.
- Refresh destination, feature, culture, map, and trust sections with stronger editorial layouts and consistent spacing.
- Update shared colors, typography, navigation, cards, buttons, and footer so the visual direction carries across the whole product.
- Keep mobile navigation and all current routes functional.

## Validation
- Check the homepage and key application pages at desktop and mobile widths.
- Verify the homepage planner still opens a populated trip plan.
- Confirm there are no visual overlaps, console errors, runtime errors, or build failures.
